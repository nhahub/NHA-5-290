# Real-Time IoT Data Pipeline & Analytics System 🚀

## 📌 Project Overview
This graduation project implements a comprehensive data pipeline that simulates and processes IoT sensor data (Temperature and Humidity). It utilizes both batch processing and real-time streaming techniques to detect anomalies, generate alerts, and visualize data through an interactive dashboard.

## 🛠️ Technology Stack
* **Programming Language:** Python
* **Data Simulation:** Python Scripts
* **Streaming & Ingestion:** Apache Kafka / Azure Event Hubs
* **Batch Processing (ETL):** Python / Azure Data Factory
* **Storage:** PostgreSQL / Azure SQL / Data Lake
* **Visualization:** Power BI / Streamlit

## 🗺️ Project Milestones
1. **Data Simulation & Ingestion:** Simulating IoT data logs and pushing them into a message queue.
2. **Batch Data Pipeline (ETL):** Extracting, transforming, and loading data into a data warehouse.
3. **Streaming Pipeline & Alerts:** Processing real-time data to raise instant alerts for threshold breaches.
4. **Dashboard & Reporting:** A real-time visualization dashboard to monitor key metrics.
